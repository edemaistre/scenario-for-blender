Scenario for Blender

Generate images, video, 3D and materials without leaving the viewport.

Scenario for Blender is a Blender extension that runs Scenario's generation models from the 3D viewport. It feeds them with what is already in your scene (a viewport capture, the scene camera, a playblast, a render) and brings the results back where you work: images as datablocks and textures, meshes at the 3D cursor, PBR materials on the selected objects, videos in your output folder. Every generation shows its price before you press Generate.

Blender 4.2+tested on 5.1, macOS, Windows, Linux
Scenario API keyPro plan or above, key + secret
Pure Pythonno wheels, GPL-3.0, open source
MCP built in16 tools for Claude Code, Cursor, Codex

Install and connect

  1. Download scenario-<version>.zip from the releases page. Keep it zipped.
  2. Drag the zip onto any Blender window, or go to Edit › Preferences › Get Extensions › Install from Disk. Blender installs and enables it. To update, install the new zip the same way, then restart Blender so the new code loads.
  3. In Scenario, create an API key: Team › API Keys, Project or Team scope, role Editor. The secret is shown once.
  4. In Blender, Edit › Preferences › Add-ons › Scenario: paste the key and the secret, press Test connection. Choose an Output Folder (default ~/Downloads/Scenario).
WherePress N in the 3D viewport and open the Scenario tab. The same form is available from the Scenario button in the viewport header (a compact popover) and from the floating composer at the bottom of the viewport.
CheckBlender's Allow Online Access (Preferences › System) must be on, otherwise every network operator refuses to run.

The panel

Every lane uses the same form, top to bottom. The parts you edit are built from the model's own schema, so a new model on Scenario appears here with the right controls without an add-on update.

Account strip
Your team and project, a refresh for the model list, a shortcut to the preferences.
Lane tabs
Image, Video, 3D, Materials, Render-to-real, MCP, Generations.
Model
The models usable in this lane, curated ones first, with the one-line description from the Scenario catalog.
Prompt
One line; the pencil opens a wider editor.
References
One box per file input the model accepts (image, video, audio, 3D). Add offers File, Viewport still, Camera still, Viewport clip, Camera clip and Render Result. Captures are taken when you press Generate.
Parameters
A checkbox in front of an optional parameter means "send this value"; unchecked, Scenario uses its default. (cost) marks the ones that change the price.
Generate (N CU)
The exact price of the form as it stands, refreshed as you edit, computed by a free dry run. "from N CU" means references that will only be uploaded at generate time are not in the quote yet.
Running, Results
Jobs in flight with progress; finished jobs with the actions of their kind (Show, Apply as texture, Add as plane, Import, Play, Tiling).

Lanes

ImageText or references to images. Show, apply as texture, add as plane. VideoText, images or a playblast of your timeline to video. 3DText, one image or several views to a mesh at the 3D cursor. MaterialsPatina PBR sets applied to the selected meshes. Render-to-realConcept still, then a finished clip from a grey playblast. GenerationsCloud history of the project, import anything into the scene. MCPLet an agent see the scene and generate on your behalf.

Image

Text or reference images to images with GPT Image 2, Gemini 3.1, Seedream, Z-Image and any other txt2img or img2img model in the catalog. Results open in an Image Editor and appear in Results with Show, Apply as texture (a material with the image as Base Color on the active mesh) and Add as plane (a view-facing plane at the 3D cursor).

Video

Text, images or your Blender scene to video with Seedance 2.0 and 2.5, Kling, Veo, Wan and the other video models.

  • Viewport clip and Camera clip references playblast your timeline at 1280×720 with overlays hidden when you press Generate. Grey clay capture forces flat single-colour shading so the model reads motion rather than materials.
  • Match timeline takes the clip duration from your frame range, rounded up to a value the model accepts. Clips shorter than 4 s are padded (Seedance's minimum); longer ones are trimmed to the model's maximum.
  • Seedance prompts get their @video1 / @image1 mentions automatically.
  • Results: Play in the system player or Play in Blender.

3D

Three modes: Text, Image (one picture) and Multi-view (several views of the same object, the first one is the front). Meshy 7 and Rodin Gen-2.5 for text; Tripo 3.1, Tripo P1, Meshy 7, Hunyuan 3.1 Pro and Rodin 2.5 for images; Meshy 7 Multi Image, Tripo 3.1 Multi View, Hunyuan 3.1 Pro Multiview and Rodin for multi-view.

The result is imported at the 3D cursor into a Scenario collection and the viewport switches to Material Preview so the textures show.

One mesh per jobProviders return several variants of one result: Meshy sends a GLB with embedded textures, a 200+ MB OBJ and the texture PNGs; Rodin with material = All sends a shaded and a PBR mesh. The add-on imports one primary mesh (the textured GLB) and lists the other files in Results with an Import button. Rodin defaults to PBR.

Materials

Patina turns a prompt or a photo into a seamless PBR set: base color, normal, roughness, metalness, height. Select the meshes to texture, describe the material, choose the maps and size, press Generate. The material arrives as a Principled BSDF with UV mapping and displacement, applied to the meshes you had selected. Tiling in Results scales the mapping.

  • PATINA Material: prompt to maps, with variation and inpainting options.
  • PATINA Image to Maps: a flat texture or photo to a full set.
  • PATINA Material Extract: isolate one material from a photo.

Render-to-real

Two steps to turn a grey animation into a finished-looking clip.

  1. Concept look. Pick the source (scene camera or viewport), describe the look, optionally add style references, press Render concept. A styled still of your capture comes back.
  2. Playblast and Generate. The timeline is playblasted (grey clay by default) and sent to Seedance 2.0 with the concept as style reference and a prompt that asks the model to keep the motion and framing of the playblast.
TipKeep a ground plane in the playblast so the model understands how the subject moves relative to the floor. Motion is followed closely; a plain grey cube over three seconds became the teapot below.

Generations

The project's cloud history: prompt, kind, price, status. Import into scene brings a result into Blender, downloading it if needed, also for generations made on the web app or by an agent. Load older pages back in time. This is also the recovery path when a download failed: the job is still there, import it again.

MCP for agents

The add-on serves the Model Context Protocol on http://127.0.0.1:9876/mcp with a bearer token that changes every Blender session. Pick a client in the MCP tab and press its button: the setup is copied to the clipboard (a Claude Code command, a Cursor mcp.json, a Claude Desktop stdio snippet, a Codex command, or a curl test).

Allow connected agents to run Python gates the execute_python tool. Off, agents keep the other fifteen tools.

Headless, without a window:

blender --background scene.blend --command scenario-mcp --port 9876 --token <token>

Floating composer

The pill at the bottom of every 3D viewport shows the current prompt and a Generate button. Click it to expand: lane tabs, the prompt, the model chip (opens the Scenario tab) and Generate with the price. In the prompt: type, arrows, Home/End, Ctrl/Cmd+V to paste, Ctrl/Cmd+A to select all, Enter to generate, Esc to leave. Click the chevron or outside the card to collapse. The composer and the panel are two views of the same form.

If drawing fails repeatedly the composer switches itself off; re-enable it in Preferences (Floating composer in the viewport).

Files and folders

Results
Your Output Folder, ~/Downloads/Scenario by default, in images/, videos/, 3d/, materials/, named <date>_<model>_<job>_<n>.<ext>.
Captures
Stills and playblasts used as references live in the extension cache (captures/ under Blender's extension user directory).
State
The job registry (so unfinished jobs resume after a restart) and the model cache sit in the extension state and cache directories, removed with the extension.
Your key
Stored in Blender's preferences file. Treat it like any credential and rotate it in Scenario if it leaks.

Troubleshooting

"Loading models..." never ends

Check the key and secret in Preferences (Test connection) and Blender's Allow Online Access. When the catalog request fails, a message and a Retry button replace the loading text.

"Prompt is required" or "Add a reference to see the cost"

The quote needs a valid form. Fill the prompt, or add the reference the model requires.

The result does not appear in the scene

Open Results. A job whose download failed says so with the reason; fetch it again from Generations › Import into scene. After installing an update, restart Blender so the new version loads.

A 3D model looks untextured

Switch the viewport to Material Preview (the add-on does this on import since 0.5.1) and check in Results which file was imported. Texture PNGs from the provider are saved next to the mesh in 3d/.

Two meshes came out of one job

Versions before 0.5.1 imported every variant of a result. Update, or delete the extra object.

Enter or the Generate button does nothing

With SCENARIO_GUI_PROBE=1 in the environment (set by the automated screenshot tool) every Generate path is disabled. Start Blender normally.

Where are the logs?

Blender's system console (Window › Toggle System Console on Windows, the terminal you launched Blender from on macOS and Linux). Messages are prefixed scenario.

Known limits

  • The prompt is single-line in the composer; the pencil in the panel opens a wider editor.
  • Captures need the Blender GUI; in --background use the MCP render_still tool instead.
  • Team-scoped keys generate into the first project; a project switcher is planned.
  • Planned for v2: skyboxes on the World, remesh, UV unwrap, retexture, part segmentation, auto-rig, text-to-motion, custom LoRAs, Scenario Workflows, sign in with Scenario, an in-Blender agent chat.
