Scenario for Blender

Generate, render and edit without leaving the viewport.

Scenario for Blender is a Blender extension that runs Scenario's generation models from the 3D viewport. It generates images, video, 3D models and PBR materials; it renders your scene as a finished still or clip from a capture of the view or a playblast of the timeline; and it edits the meshes you already have with Scenario's 3D tools. Results come back where you work: images as datablocks and textures, meshes at the cursor or next to their original, materials on the selected objects, videos in your output folder. Every generation shows its price before you press Generate.

Blender 4.2+tested on 5.1, macOS, Windows, Linux
Scenario API keyPro plan or above, key + secret
Pure Pythonno wheels, GPL-3.0, open source
MCP built in17 tools for Claude Code, Cursor, Codex

Install and connect

  1. Download scenario-<version>.zip from the releases page. Keep it zipped.
  2. Drag the zip onto any Blender window, or go to Edit › Preferences › Get Extensions › Install from Disk. Blender installs and enables it. To update, install the new zip the same way, then restart Blender so the new code loads.
  3. In Scenario, create an API key: Team › API Keys, Project or Team scope, role Editor. The secret is shown once.
  4. In Blender, Edit › Preferences › Add-ons › Scenario: paste the key and the secret, press Test connection. Choose an Output Folder (default ~/Downloads/Scenario).
WherePress N in the 3D viewport and open the Scenario tab: four panels, Scenario, Jobs, Generations, Agents. The Scenario button in the viewport header opens the same tab. The floating composer at the bottom of the viewport is the quick path.
CheckBlender's Allow Online Access (Preferences › System) must be on, otherwise every network operator refuses to run.

The four panels

Scenario
What to generate. Lane tabs: Image, Video, 3D, Materials, Render Image, Render Video, Edit 3D. Below them, the form of the lane.
Jobs
What is running, all lanes together, with a count in the header: "Prompt Spark is writing the look", "uploading and submitting", "rendering 40%".
Generations
What came back. This session's results with their actions and an Inputs strip showing the images used in the inference; then, with the globe toggle on, the project's cloud history (generations made on the web app, by agents or on another machine) with Import into scene and Load older.
Agents (MCP)
The local MCP server: status, token, one-click client setups, the Python permission.

The tabs answer "what do I want to make"; the panels below answer "what is running" and "what did I get", whatever the lane.

The form

Every lane uses the same form, top to bottom. The parts you edit are built from the model's own schema, so a new model on Scenario appears here with the right controls without an add-on update.

Account strip
Your team and project, a refresh for the model list, a shortcut to the preferences.
Model
A button with the current model. It opens the model picker: a search field, filter chips (All, Featured, Scenario, Partners, Recent), the list with thumbnails and the description of the highlighted model. The small arrow next to it is the plain dropdown.
Prompt
One line; the pencil opens a wider editor.
References
One box per file input the model accepts (image, video, audio, 3D), a thumbnail per file. Add offers File, Viewport still, Camera still, Viewport clip, Camera clip and Render Result. Captures are taken when you press Generate. Pinned rows are inputs the lane adds itself: the capture, the selected mesh.
Parameters
A checkbox in front of an optional parameter means "send this value"; unchecked, Scenario uses its default. (cost) marks the ones that change the price.
Generate (N CU)
The exact price of the form as it stands, refreshed as you edit, computed by a free dry run. "from N CU" means references that will only be uploaded at generate time are not in the quote yet.

Lanes

ImageText or references to images. Show, apply as texture, add as plane. VideoText, images or a playblast of your timeline to video. 3DText, one image or several views to a mesh at the 3D cursor. MaterialsPatina PBR sets applied to the selected meshes. Render ImageYour view, rendered as a finished still. Prompt Spark writes the look if you don't. Render VideoA playblast, rendered as a finished clip, with a camera path planner. Edit 3DRetexture, retopology, rigging, animation, UV unwrap, segmentation of the selected mesh. GenerationsPanel: results of this session and the project's cloud history. Agents (MCP)Panel: let an agent see the scene, plan a camera move and generate.

Image

Text or reference images to images with GPT Image 2, Gemini 3.1, Seedream, Z-Image and any other txt2img or img2img model in the catalog. Results open in an Image Editor and appear in Generations with Show, Apply as texture (a material with the image as Base Color on the active mesh), Add as plane (a view-facing plane at the 3D cursor) and Use as video first frame.

Video

Text, images or your Blender scene to video with Seedance 2.0 and 2.5, Kling, Veo, Wan and the other video models.

  • Viewport clip and Camera clip references playblast your timeline at 1280×720 with overlays hidden when you press Generate. Grey clay capture forces flat single-colour shading so the model reads motion rather than materials.
  • Match timeline takes the clip duration from your frame range, rounded up to a value the model accepts. Clips shorter than 4 s are padded (Seedance's minimum); longer ones are trimmed to the model's maximum.
  • Seedance prompts get their @video1 / @image1 mentions automatically.
  • Results: Play in the system player or Play in Blender.

3D

Three modes: Text, Image (one picture) and Multi-view (several views of the same object, the first one is the front). Meshy 7 and Rodin Gen-2.5 for text; Tripo 3.1, Tripo P1, Meshy 7, Hunyuan 3.1 Pro and Rodin 2.5 for images; Meshy 7 Multi Image, Tripo 3.1 Multi View, Hunyuan 3.1 Pro Multiview and Rodin for multi-view.

The result is imported at the 3D cursor into a Scenario collection and the viewport switches to Material Preview so the textures show. In Generations, Add to scene imports the primary mesh again at the cursor and Select selects the objects the job created.

One mesh per jobProviders return several variants of one result: Meshy sends a GLB with embedded textures, a 200+ MB OBJ and the texture PNGs; Rodin with material = All sends a shaded and a PBR mesh. The add-on imports one primary mesh (the textured GLB) and lists the other files with an Add button. Rodin defaults to PBR.

Materials

Patina turns a prompt or a photo into a seamless PBR set: base color, normal, roughness, metalness, height. Select the meshes to texture, describe the material, choose the maps and size, press Generate. The material arrives as a Principled BSDF with UV mapping and displacement, applied to the meshes you had selected. Tiling in Generations scales the mapping.

  • PATINA Material: prompt to maps, with variation and inpainting options.
  • PATINA Image to Maps: a flat texture or photo to a full set.
  • PATINA Material Extract: isolate one material from a photo.

Render Image

Your view, rendered as a finished still by an image edit model: a capture of the viewport or the scene camera, optional style images, a look.

  • Scene to render: Viewport (what you see) or Scene camera; Grey clay capture when the model should ignore your materials.
  • Model: Gemini 3.1, GPT Image 2, Seedream 5.0 Pro, FLUX 2 (Max / Pro), Reve Remix, Qwen Edit 2511, MAI Image 2.5 Pro Edit, Grok Imagine Image 2.0, Z-Image first; every other img2img model through the picker.
  • Look: what the render should look like ("weathered steampunk copper, overcast light"). Leave it empty and Prompt Spark writes it: a capture of the view goes to Scenario's prompt writer (0.75 CU), which describes materials, lighting and mood; the look it wrote stays on the lane and with the result.
  • Style images: optional references for palette, materials and lighting. The capture is always image 1.
The promptEvery input has a stated role. Image 1 is the exact scene: every object, its position, the camera, the framing and the perspective are frozen, nothing may be added, moved or removed. The other images are look references only and none of their content may appear. The result lands in Generations and becomes the first frame of Render Video.

Render Video

A playblast of your timeline, rendered as a finished clip by a video model that takes a reference video.

  • Clip to render: Viewport clip or Camera clip, frame range and duration, Grey clay capture, Match timeline.
  • Camera path: type the shot ("slow orbit, 8 s, 35mm") and press Plan, or pick a preset (Orbit, Push in, Pull back, Crane, Pan, Flyover) with a duration and a focal length, or place numbered markers: At cursor and From view add Shot 1, Shot 2... (small cameras; select one to set its own focal length and hold time). Build camera path creates the Scenario Shot Camera, keyframes it through the markers or around the subject, aims it at the subject and sets the frame range. Preview plays it in camera view. Camera clip then records exactly that move.
  • Model: Seedance 2.0, Minimax H3, Seedance 2.5 and Mini, Runway Aleph 2, Happy Horse Video Edit, Gemini Omni Edit, Grok Edit Video first; every other video2video model through the picker. They take the video plus images, often many.
  • Look: as in Render Image; empty means Prompt Spark writes it from a still of the first frame.
  • First frame: the latest Render Image result is proposed automatically and sent as the first frame (Seedance's image, H3's firstFrameImage) so the clip starts exactly from your rendered still. Any image result offers Use as video first frame.
The promptThe playblast is the exact scene, camera move and timing to reproduce; the first frame is the look to match through the whole clip; the other images are style only. Seedance gets @video1 / @image1 tags, the other models plain words.

Edit 3D

Scenario's 3D tools on a mesh that is already in your scene.

  1. Select the mesh (or several) in the viewport.
  2. Pick the task: Retexture (Meshy 7 Retexture, Tripo Texturing, Trellis 2 Retexture, Tencent Texture Edit), Retopology (Tripo Retopology, Meshy Remesh, Hunyuan Polygen), Rigging (Meshy, Tripo 2.5, Cartwheel), Animation (Meshy Animation, Cartwheel Text to Motion), UV unwrap (Meshy, Tencent), Segment (Tripo Segmentation, Hunyuan 3D Part, Hitem3D Split), Stylize, or All.
  3. Fill the model's parameters (a style prompt or image for retexturing, a face limit for retopology, a height for rigging) and Generate.

The selection is exported as a GLB at generate time (modifiers applied, materials embedded) and uploaded; the result is imported next to the original, bottoms aligned, named after it.

Generations

This session's results with their actions, then the project's cloud history: prompt, kind, price, status. Import into scene brings a result into Blender, downloading it if needed, also for generations made on the web app or by an agent. Load older pages back in time. This is also the recovery path when a download failed: the job is still there, import it again.

Agents (MCP)

The add-on serves the Model Context Protocol on http://127.0.0.1:9876/mcp with a bearer token that changes every Blender session. Pick a client in the Agents panel and press its button: the setup is copied to the clipboard (a Claude Code command, a Cursor mcp.json, a Claude Desktop stdio snippet, a Codex command, or a curl test).

Allow connected agents to run Python gates the execute_python tool. Off, agents keep the other sixteen tools.

Floating composer

The pill at the bottom of every 3D viewport shows the current prompt and a Generate button. Click it to expand: lane tabs (Image, Video, 3D, Materials, Render Img, Render Vid), the prompt, the model chip (opens the model picker), a Settings chip (opens the sidebar) and Generate with the price. The composer is the quick path: it uses the settings of the current lane as they stand in the sidebar.

Editing the prompt: click to place the caret, drag or Shift+arrows to select, double-click selects a word, Home/End, Ctrl/Cmd+A selects all, Ctrl/Cmd+C copies, Ctrl/Cmd+X cuts, Ctrl/Cmd+V pastes, typing replaces the selection, Enter generates, Esc leaves. The minus button in the top-right corner collapses the card; clicking outside also does. If drawing ever fails repeatedly the composer switches itself off; re-enable it in Preferences (Floating composer in the viewport).

Costs

Prices are in Creative Units (CU), charged to the workspace of your API key. They depend on the model and its cost-marked parameters; the quote on the Generate button is exact for the form you see, and the Prompt Spark call is added when the look is empty. Files and folders

Results
Your Output Folder, ~/Downloads/Scenario by default, one folder per kind and per day: images/20260828/, videos/20260828/, 3d/20260828/, materials/20260828/, files named <date>_<model>_<job>_<n>.<ext>.
Captures
Stills, playblasts, Prompt Spark stills and Edit 3D exports live in the extension cache (captures/, exports/ under Blender's extension user directory); model thumbnails in thumbs/.
State
The job registry (so unfinished jobs resume after a restart), recent models and the model cache sit in the extension state and cache directories, removed with the extension.
Your key
Stored in Blender's preferences file. Treat it like any credential and rotate it in Scenario if it leaks.

Troubleshooting

"Loading models..." never ends

Check the key and secret in Preferences (Test connection) and Blender's Allow Online Access. When the catalog request fails, a message and a Retry button replace the loading text.

"Prompt is required" or "Add a reference to see the cost"

The quote needs a valid form. Fill the prompt, or add the reference the model requires.

"Select the mesh to edit" or "Price shown after the upload"

Edit 3D needs a mesh object selected in the viewport; its price is known once the mesh is uploaded, Generate works anyway.

"This model takes no image/video input"

The picked model cannot receive the capture; choose another one in the Render lane.

The result does not appear in the scene

Open Generations. A job whose download failed says so with the reason; fetch it again with Import into scene. After installing an update, restart Blender so the new version loads.

The rendered image moved things around

The prompt already freezes the layout; give the model a cleaner capture (Grey clay capture, a camera view rather than a wide viewport) and fewer style images, and keep the look about materials and light, not about content.

A 3D model looks untextured

Switch the viewport to Material Preview (the add-on does this on import) and check in Generations which file was imported. Texture PNGs from the provider are saved next to the mesh.

Enter or the Generate button does nothing

With SCENARIO_GUI_PROBE=1 in the environment (set by the automated screenshot tool) every Generate path is disabled. Start Blender normally.

Where are the logs?

Blender's system console (Window › Toggle System Console on Windows, the terminal you launched Blender from on macOS and Linux). Messages are prefixed scenario.

Known limits

  • The prompt is single-line in the composer; the pencil in the panel opens a wider editor. The composer shows six lanes; Edit 3D lives in the sidebar (its input is the selection).
  • Captures need the Blender GUI; in --background use the MCP render_still tool instead.
  • MCP generate sends parameters as given: the role-explicit render prompts and Prompt Spark run from the panel and the composer.
  • Team-scoped keys generate into the first project; a project switcher is planned. Skyboxes, custom LoRAs, Scenario Workflows and sign-in with Scenario are still planned.
